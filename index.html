Expo Asset Generator

How to use:

  1. Upload your logo (preferably a square PNG with transparency)
  2. Choose a background color for the icons
  3. Preview the generated assets
  4. Download individual assets or all at once

I hope you enjoyed using this tool! Hit me up @ViralManager

📱 Where to put your files:

1. Create the following directory structure in your Expo project if it doesn't exist: 

assets/
  ├── images/
  │   ├── icon.png           (1024×1024)
  │   ├── adaptive-icon.png  (1024×1024)
  │   ├── splash-icon.png    (200×200)
  │   └── favicon.png        (32×32)

2. Update your app.json to reference these files:

{
  "expo": {
    "icon": "./assets/images/icon.png",
    "splash": {
      "image": "./assets/images/splash-icon.png",
      "resizeMode": "contain",
      "backgroundColor": "#ffffff"  // Use your chosen background color
    },
    "android": {
      "adaptiveIcon": {
        "foregroundImage": "./assets/images/adaptive-icon.png",
        "backgroundColor": "#ffffff"  // Use your chosen background color
      }
    }
  }
}

Note: Expo will automatically generate all required sizes for each platform from these base assets.
