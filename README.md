# Expo Asset Generator

A simple, browser-based tool to generate all required assets for your Expo app from a single logo. No installation, no dependencies, just open and use!

## 🚀 Features

- Generate all required Expo assets in one click
- Live preview of all generated assets
- Customizable background color
- Downloads as a ready-to-use ZIP with correct directory structure
- Includes pre-configured app.json template
- Works entirely in your browser - no server needed
- No dependencies or installation required

## 📱 Generated Assets

- `icon.png` (1024×1024) - Main app icon
- `adaptive-icon.png` (1024×1024) - Android adaptive icon
- `splash-icon.png` (200×200) - Splash screen icon
- `favicon.png` (32×32) - Web favicon

## 🔧 How to Use

1. Visit [https://rasha-rahman123.github.io/expo-asset-generator](https://rasha-rahman123.github.io/expo-asset-generator)
2. Upload your logo (preferably a square PNG with transparency)
3. Choose a background color
4. Download the ZIP file
5. Extract into your Expo project
6. Done! 🎉

## 💡 Why Use This?

Setting up assets for an Expo app usually involves creating multiple sizes and configurations. This tool automates the entire process, saving you time and ensuring all assets meet Expo's requirements.

## 🛠 Technical Details

- Pure HTML/JavaScript solution
- Uses Canvas API for image processing
- Generates platform-specific assets to Expo specifications
- Creates proper directory structure
- Includes configured app.json template
